Put your copy of Hollow Knight here, then launch Hollow Knight from the Ports menu:

  Hollow Knight for Linux from GOG (version 1.5.12620, Unity 6000.0.61f1): GOG's installer (hollow_knight_*.sh) or the installed game folder.

Optional: UnitySetup-Android-Support-for-Editor-<version>.exe (from Unity's download archive, the
version the game was built with); otherwise the setup downloads what it needs from Unity (about
10 MB, Wi-Fi needed). The first launch builds the game on the handheld (one to three hours, once); it
uses up the game's folder here. See ../README.md.
